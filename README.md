# Algoritmo FLS — Osteoporosis

Herramienta web de apoyo a la decisión clínica para el **Fracture Liaison Service (FLS)** del Servicio de Medicina Física y Rehabilitación del Hospital Universitario Doctor Peset (Valencia).

Basada en las guías SEIOMM 2022 y en las fichas técnicas de la AEMPS/EMA.

## Uso
Abre la aplicación en el navegador desde la dirección web publicada. En iPhone: Safari → Compartir → *Añadir a pantalla de inicio*.

La aplicación no guarda ni envía datos: todo se procesa en el propio dispositivo y se borra al cerrar la página.

## Aviso
Herramienta de apoyo a la decisión clínica. No sustituye el juicio del facultativo.
